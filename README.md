# 萌芽守卫战 Sprout Siege

借用植物大战僵尸故事设定的 3D 第一人称网页游戏。

你是一个透明的园丁，僵尸看不见你。僵尸从草坪对面的墓地出发，穿过草坪想走进小屋。
捡天上掉下的阳光（每个 30），到草坪右侧的卡槽光束里买植物，别让任何一只僵尸进屋。

## 第一波

| 植物 | 价格 | 能力 |
| --- | --- | --- |
| 机枪射手 | 40 | 一次连发 6 颗豌豆 |
| 毁灭菇 | 20 | 种下后爆炸，蘑菇云范围伤害；留下弹坑，60 秒内不能种植物 |
| 阳光大地 | 50 | 投掷黑洞，把周围僵尸吸进去后爆炸：一半炸成灰，一半变成阳光魅惑僵尸 |
| 电能超级机枪豌豆 | 150 | 电能豌豆无视护甲（直接扣本体血），每颗有 10% 概率直接电死僵尸；每次攻击都开大招：13 颗电能豌豆从正前方一左一右依次扇形散开 |
| 玉米加农炮 | 100 | 不会自己攻击。走到炮旁边连上它，再走到目标位置按 E 发射；8×8 范围，普通僵尸直接炸飞，铁桶僵尸原地炸死；冷却 20 秒；落点留下弹坑（弹坑照样可以瞄准） |

| 僵尸 | 血量 | 击杀奖励 |
| --- | --- | --- |
| 普通僵尸 | 6 发豌豆 | 10 阳光 |
| 铁桶僵尸 | 铁桶 12 发 + 本体 6 发 | 20 阳光 |

阳光魅惑僵尸会走回墓地并攻击路上的僵尸，它死掉时会掉下一个阳光。

## 操作

- `W` `A` `S` `D`：移动
- 鼠标：看方向
- `Shift`：奔跑
- 走进卡槽光束正中央：购买植物
- `E`：把手上的植物种在脚下的格子里；连着玉米加农炮时，朝脚下发射
- `Q`：把手上的植物放回（退还阳光）；或取消玉米加农炮瞄准
- 走到玉米加农炮旁边：连上它（装填中会提示剩余秒数）
- `Esc`：暂停

## 开发

```bash
npm install
npm run dev      # 打开 http://localhost:5173
npm run build    # 打包到 dist/
```

推送到 `main` 分支后，GitHub Actions 会自动发布到 GitHub Pages。

## 代码结构

- `src/main.ts`：入口，渲染循环、开始/暂停
- `src/world.ts`：场景布局（草坪、小屋、墓地、灯光）
- `src/player.ts`：透明玩家的第一人称移动
- `src/sun.ts`：阳光掉落与拾取
- `src/game.ts`：波次、种植、弹坑、胜负判定
- `src/zombies.ts`：僵尸模型、血量、啃食、魅惑
- `src/plants.ts`：植物模型与攻击、豌豆、黑洞
- `src/shop.ts`：卡槽与光束
- `src/effects.ts`：蘑菇云、爆炸、烟雾等特效
- `src/hud.ts`：界面上的计数与提示
